# Bundled fonts

These typefaces are embedded into the plugin binary so the panel looks identical
on Linux, macOS and Windows (and in the offline screenshot renderer).

| MichromaRegular.ttf | Michroma | https://github.com/googlefonts/michroma | SIL OFL 1.1 |
| JetBrainsMonoRegular.ttf / Bold | JetBrains Mono | https://github.com/JetBrains/JetBrainsMono | SIL OFL 1.1 |
